# Cessna Aircraft Recreation

## Overview
Recreated a Cessna aircraft as the final project for my Indian Space Lab internship.

## Tools Used
- OpenVSP
- Autodesk Fusion 360
- Blender

## What I Did
- Modeled the aircraft geometry and fuselage.
- Created design views and renders.
- Analyzed the aircraft layout and components.

## Files
- `models/cessna_model.f3d` — editable Fusion 360 model
- `openvsp/cessna_geometry.vsp` — OpenVSP aircraft geometry
- `renders/` — visual renders of the final model

## What I Learned
- Aircraft component layout
- 3D modeling and design documentation
- OpenVSP and Fusion 360 workflows
